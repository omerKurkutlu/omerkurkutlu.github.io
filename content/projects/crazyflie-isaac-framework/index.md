## Overview

The Crazyflie Isaac Framework (CIF) is an open-source robotics simulation framework built on NVIDIA Isaac Sim for Crazyflie nano-drone research. It brings configurable controllers, sensors, environments, and autonomous algorithms together in a single modular stack.

## Key Features

- Configurable flight controllers and sensor models
- Customizable simulation environments
- Deep reinforcement learning training and evaluation
- Multi-drone experiments
- Benchmarking of autonomous navigation algorithms
- Sim-to-real experimentation with Crazyflie 2.x hardware

## Project Status

**Status:** ✅ Open-sourced — developed as part of my PhD research at the University of Illinois Chicago.
